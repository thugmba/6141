MODULE 34. Data Basics
AI, ML, DL, and When a Rule Is Enough
KEY POINTS
  • Three nested ideas:
  • Rule or ML?
    • Use a rule when the policy is fixed and written down: "sales tax is 5% of the price". A rule is cheaper, exact, and easy to explain.
    • Use ML when the pattern is complex or changes over time, and you have many past examples with known outcomes: "which invoices look like fraud?"
  • ML makes a prediction; a person or a business rule still decides what to do with it.
AT A GLANCE
TermWhat it isBusiness example
AI (Artificial Intelligence)any computer system that does a task we link to human thinkinga chatbot answering customers
ML (Machine Learning)AI that learns a rule from past examples instead of being told the ruleflagging likely fraud from past fraud cases
DL (Deep Learning)ML with many-layered neural networks, for images, sound, and textreading scanned invoices

MODULE 36. Keywords
6 Terms You Need Today
TERM 1

Artificial Intelligence (AI)

What: computer systems that do tasks we link to human thinking

Why: the umbrella term in every vendor pitch; ask which kind of AI is inside

TERM 2

Machine Learning (ML)

What: a system that learns a decision rule from past examples

Why: handles patterns too complex to write down by hand

TERM 3

Deep Learning (DL)

What: ML with many-layered neural networks

Why: needed for images, sound, and free text; costly to build and run

TERM 4

Rule-Based System

What: code that follows rules a person wrote, such as if amount > 250000:

Why: the right choice when the policy is clear and fixed

TERM 5

Payback Period

What: months until the net benefit repays the build cost

Why: shows how fast the money comes back

TERM 6

ROI (Return on Investment)

What: total gain compared with the cost, in percent

Why: compares projects of different sizes on one scale

MODULE 39. Code Demonstration 1
Payback and ROI for Every Proposal
 YourName_S31_demo_1.pyInput → Process → Output
# 1. Input: load the 10 proposals
import pandas as pd
df = pd.read_csv("data/session_03_01_dataset.csv")

# 2. Process: net benefit, payback, and 3-year ROI
df["Net_Annual_Benefit_USD"] = (
    df["Projected_Cost_Savings_USD"] - df["Implementation_Cost_USD"] * 0.15
)
df["Payback_Months"] = (
    df["Implementation_Cost_USD"] / df["Net_Annual_Benefit_USD"] * 12
).round(1)
df["ROI_3yr_Pct"] = (
    (df["Net_Annual_Benefit_USD"] * 3 - df["Implementation_Cost_USD"])
    / df["Implementation_Cost_USD"] * 100
).round(1)

# 3. Output: the 3 proposals with the highest ROI
top3 = df.sort_values("ROI_3yr_Pct", ascending=False).head(3)
print(top3[["Project_ID", "Department_Name", "Payback_Months", "ROI_3yr_Pct"]])
HOW IT WORKS
  • df["Implementation_Cost_USD"] * 0.15 is the yearly running cost; subtracting it from the projected savings gives the net annual benefit, for all 10 proposals at once.
  • The payback divides the build cost by the net benefit and multiplies by 12 to turn years into months.
  • The 3-year ROI compares 3 years of net benefit with the build cost, in percent (section 7.2).
READ THE OUTPUT
  • Both Fraud Operations projects pay back in under 5 months and return about 7 times their cost over 3 years.

MODULE 39. Code Demonstration 2
A Fixed Rule vs a Rule Learned from Examples
 YourName_S31_demo_2.pyInput → Process → Output
# 1. Input: 10 past invoices, checked by auditors (fictional)
import pandas as pd
past = pd.DataFrame({
    "Amount_USD": [120000, 180000, 210000, 240000, 260000,
                   300000, 330000, 410000, 450000, 520000],
    "Was_Fraud": [False] * 5 + [True] * 5,
})

# 2. Process: a rule a person chose vs a threshold learned from the data
rule_flags = past["Amount_USD"] > 250000
rule_mistakes = (rule_flags != past["Was_Fraud"]).sum()

best_threshold, best_mistakes = None, len(past)
for threshold in past["Amount_USD"]:
    flags = past["Amount_USD"] >= threshold
    mistakes = (flags != past["Was_Fraud"]).sum()
    if mistakes < best_mistakes:
        best_threshold, best_mistakes = threshold, mistakes

# 3. Output: compare the mistakes
print("Fixed rule (above 250,000) mistakes:", rule_mistakes)
print("Learned threshold:", best_threshold, "mistakes:", best_mistakes)
HOW IT WORKS
  • pd.DataFrame({...}) builds 10 fictional past invoices with known answers.
  • past["Amount_USD"] > 250000 applies the person's rule and gives one True / False per invoice.
  • (rule_flags != past["Was_Fraud"]).sum() counts the rows where the rule and the auditors disagree: the mistakes.
READ THE OUTPUT
Fixed rule (above 250,000) mistakes: 1 Learned threshold: 300000 mistakes: 0
  • The person's rule flags the honest 260000 invoice: 1 mistake.

MODULE 39. Code Demonstration 3
A Shortlist That Does Not Fit the Budget
 YourName_S31_demo_3.pyInput → Process → Output
# 1. Input: load the proposals and add the payback period
import pandas as pd
df = pd.read_csv("data/session_03_01_dataset.csv")
df["Net_Annual_Benefit_USD"] = (
    df["Projected_Cost_Savings_USD"] - df["Implementation_Cost_USD"] * 0.15
)
df["Payback_Months"] = (
    df["Implementation_Cost_USD"] / df["Net_Annual_Benefit_USD"] * 12
).round(1)

# 2. Process: fast payback AND many hours saved
shortlist = df[
    (df["Payback_Months"] <= 7.0)
    & (df["Annual_Labor_Hours_Saved_Count"] >= 4000)
]
shortlist_cost = shortlist["Implementation_Cost_USD"].sum()

# 3. Output: compare the shortlist with the budget
print(shortlist[["Project_ID", "Department_Name", "Payback_Months"]])
print(f"Shortlist cost: ${shortlist_cost:,.0f} against a budget of $500,000")
HOW IT WORKS
  • Part 1 recomputes the net benefit and payback, as in Micro-Example 1.
  • The two conditions keep projects that pay back within 7 months and save at least 4,000 hours a year; each condition is in its own brackets, joined with & (Session 1.4).
  • shortlist["Implementation_Cost_USD"].sum() adds up what the shortlist would cost.
READ THE OUTPUT
Project_ID Department_Name Payback_Months 0 AI-PRJ-101 Supply Chain 6.6 3 AI-PRJ-104 Finance 6.6 ...
  • 6 projects pass both rules, but together they cost more than twice the budget.
