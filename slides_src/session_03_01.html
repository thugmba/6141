Step 1: Count the Old Rule's Mistakes
 YourName_S31_step_1.pyInput → Process → Output
# 1. Input: 20 past emails, each marked spam or not by its reader
import pandas as pd
df = pd.read_csv("data/session_03_01_dataset.csv")

# 2. Process: apply the rule and compare it with the real answers
df["Flagged"] = df["Link_Count"] >= 3
df["Is_Mistake"] = df["Flagged"] != (df["Is_Spam_Binary"] == 1)

# 3. Output: the mistakes and how many there are
mistakes = df[df["Is_Mistake"]]
print(mistakes[["Subject", "Link_Count", "Is_Spam_Binary"]])
print("Mistakes:", df["Is_Mistake"].sum(), "of", len(df))
HOW IT WORKS
  • >= 3 applies the rule to all 20 emails at once: True = spam folder
  • == 1 turns the answer 1 / 0 into True / False
  • != marks a mistake: the rule and the real answer disagree
  • .sum() counts the True values
OUTPUT
Subject Link_Count Is_Spam_Binary 3 Weekly news from the campus 3 0 4 Verify your bank account now 2 1 9 Club dinner photos 3 0 17 Flight booking confirmation 3 0 Mistakes: 4 of 20

Quick Check: add df["Flagged"].mean(): the share sent to spam is 0.55

MODULE 3Step 2
Step 2: Let the Data Choose the Threshold
 YourName_S31_step_2.pyInput → Process → Output
# 1. Input: the same 20 past emails
import pandas as pd
df = pd.read_csv("data/session_03_01_dataset.csv")
is_spam = df["Is_Spam_Binary"] == 1

# 2. Process: one function counts the mistakes of any threshold
def count_mistakes(threshold):
    flagged = df["Link_Count"] >= threshold
    return (flagged != is_spam).sum()

# 3. Output: try thresholds from 1 to 6 links
for threshold in [1, 2, 3, 4, 5, 6]:
    print(f"{threshold}+ links: mistakes {count_mistakes(threshold)}")
HOW IT WORKS
  • count_mistakes() packs Step 1 into a function (Session 2.4)
  • The for loop tries each threshold and prints its mistakes
  • Trying rules and keeping the best is the "learning" in machine learning
OUTPUT
1+ links: mistakes 8 2+ links: mistakes 5 3+ links: mistakes 4 4+ links: mistakes 1 5+ links: mistakes 2 6+ links: mistakes 4

Quick Check: use range(1, 10, 2): the best of 1, 3, 5, 7, 9 is 5; the step skipped 4

MODULE 3Step 3
Step 3: Test Both Rules on New Emails
 YourName_S31_step_3.pyInput → Process → Output
# 1. Input: the past emails and next month's new emails
import pandas as pd
past = pd.read_csv("data/session_03_01_dataset.csv")
new = pd.read_csv("data/session_03_01_new_messages.csv")

# 2. Process: accuracy = the share of emails the rule gets right
def accuracy(data, threshold):
    flagged = data["Link_Count"] >= threshold
    return (flagged == (data["Is_Spam_Binary"] == 1)).mean()

# 3. Output: both rules, on past and on new emails
for name, threshold in [("Old rule", 3), ("Learned rule", 4)]:
    print(f"{name} ({threshold}+ links): past {accuracy(past, threshold):.0%}, "
          f"new {accuracy(new, threshold):.0%}")
HOW IT WORKS
  • The function takes the table too, so one function scores past and new emails
  • == marks correct decisions; .mean() turns them into accuracy
  • :.0% prints 0.95 as 95%
OUTPUT
Old rule (3+ links): past 80%, new 60% Learned rule (4+ links): past 95%, new 80%

Quick Check: add ("Strict rule", 6): past 80%, new 80%

Exercise 1: Missed Spam or False Alarm?
 YourName_S31_mistakes.pyInput → Process → Output
# 1. Input: the 20 past emails
import pandas as pd
df = pd.read_csv("data/session_03_01_dataset.csv")
is_spam = df["Is_Spam_Binary"] == 1

# 2. Process: count the two kinds of mistakes for one threshold
def mistake_report(threshold):
    flagged = df["Link_Count"] >= threshold
    missed = (flagged == False) & is_spam
    false_alarm = flagged & (is_spam == False)
    print(f"{threshold}+ links: missed spam {missed.sum()}, "
          f"false alarms {false_alarm.sum()}")
    print("  Missed:", list(df.loc[missed, "Subject"]))

# 3. Output: the old rule and the learned rule
mistake_report(3)
mistake_report(4)
TYPE, RUN, INTERPRET
  • (flagged == False) & is_spam = spam that reached the inbox
  • df.loc[missed, "Subject"] lists those emails
  • In two comment lines: which mistake did the learned rule remove? Why can no link threshold catch "Verify your bank account now"?

Check: old rule: missed spam 1, false alarms 3; learned rule: missed spam 1, false alarms 0
