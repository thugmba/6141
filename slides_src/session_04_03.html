  3. "How do we clear the stock in time?" Calculate the price cut each product needs to sell out before the season ends, and fix a SyntaxError (an unclosed bracket)

MODULE 43. Business Context
Price, Volume, and Profit
KEY POINTS
  • A lower price sells more units but earns less on each one; a higher price earns more per unit but sells fewer.
  • Price elasticity of demand (PED): if elasticity is -1.5, a 1% price increase loses about 1.5% of units.
  • The goal is profit, not revenue: a cut can raise revenue and still lower profit, because each extra unit brings in less margin.
  • Seasonal stock: units left at the season's end lose most of their value.

MODULE 44. Data Basics
Measuring Elasticity with a Price Test
KEY POINTS
  • To measure how customers react, the retailer changed the price of PRD-202 once a week for 5 weeks and recorded daily units sold:
  • Elasticity is the slope of a straight line through log(units) against log(price).
  • np.polyfit(x, y, 1) fits that straight line and returns its slope and intercept.
  • Using elasticity for a small price change: new units = old units x (1 + elasticity x price change).

MODULE 46. Keywords
6 Terms You Need Today
TERM 1

Price Elasticity of Demand (PED)

What: the % change in units sold for a 1% change in price

Why: tells you whether a price rise loses a few customers or many

TERM 2

Unit Margin and Gross Profit

What: price minus unit cost, and unit margin times units sold

Why: the measure a pricing decision should maximize

TERM 3

Price Simulation

What: computing units and profit for several possible prices before choosing one

Why: test a decision on paper, not on real customers

TERM 4

Days of Stock

What: inventory divided by daily sales

Why: shows which products will not sell out in time

TERM 5

Markdown

What: a planned price cut to sell stock faster

Why: a smaller, earlier cut usually loses less than a fire sale at the end

TERM 6

Salvage Value

What: what leftover stock is still worth after the season

Why: decides how costly it is to be left with unsold units

MODULE 49. Code Demonstration 1
Estimate Elasticity from the Price Test
 YourName_S43_demo_1.pyInput → Process → Output
# 1. Input: 5 weeks of tested prices for PRD-202
import numpy as np
import pandas as pd
test = pd.read_csv("data/session_04_03_price_test.csv")

# 2. Process: a straight line through log(units) against log(price)
slope, intercept = np.polyfit(np.log(test["Test_Price_USD"]),
                              np.log(test["Avg_Daily_Units"]), 1)
elasticity = round(slope, 2)

# 3. Output: the elasticity and what it means
print("Price elasticity of demand:", elasticity)
print(f"A 1% price rise loses about {abs(elasticity)}% of units sold.")
HOW IT WORKS
  • import numpy as np loads NumPy, the number library that pandas is built on.
  • np.log(...) takes the logarithm of every price and every unit count (section 7.2).
  • np.polyfit(x, y, 1) fits the best straight line through the 5 points and returns its slope and intercept.
READ THE OUTPUT
Price elasticity of demand: -1.51 A 1% price rise loses about 1.51% of units sold.
  • -1.51 is below -1: customers of this product react strongly to price.

MODULE 49. Code Demonstration 2
Simulate Profit for Several Price Changes
 YourName_S43_demo_2.pyInput → Process → Output
# 1. Input: the catalog and the elasticity from Micro-Example 1
import pandas as pd
df = pd.read_csv("data/session_04_03_dataset.csv")
elasticity = -1.51

# 2. Process: one function, used for every price change
def simulate(price_change):
    price = df["Current_Price_USD"] * (1 + price_change)
    units = df["Historical_Daily_Sales_Units"] * (1 + elasticity * price_change)
    return round(((price - df["Unit_Cost_USD"]) * units).sum(), 2)

profit_curve = {}
for change in [-0.10, -0.05, 0.0, 0.05, 0.10]:
    profit_curve[f"{change * 100:+.0f}%"] = simulate(change)

# 3. Output: daily gross profit for the whole catalog at each change
for label, profit in profit_curve.items():
    print(f"{label}: ${profit:,.2f}")
HOW IT WORKS
  • elasticity = -1.51 uses the value measured in Micro-Example 1 for every product.
  • simulate(price_change) computes the new price, the new units (section 7.3), and the total daily gross profit of the whole catalog.
  • The loop runs the function for 5 price changes and stores each result in a dictionary, labeled like +5%.
READ THE OUTPUT
-10%: $6,881.85 -5%: $7,163.83 +0%: $7,342.85 ...
  • Profit rises from -10% up to +5%, then falls again at +10%: there is a best point in between.

MODULE 49. Code Demonstration 3
Which Products Will Not Sell Out in 12 Days?
 YourName_S43_demo_3.pyInput → Process → Output
# 1. Input: the catalog
import pandas as pd
df = pd.read_csv("data/session_04_03_dataset.csv")
season_days = 12

# 2. Process: days of stock and our price gap to the competitor
df["Days_Of_Stock"] = (
    df["Inventory_Units_Count"] / df["Historical_Daily_Sales_Units"]
).round(1)
df["Price_Gap_Pct"] = (
    (df["Current_Price_USD"] - df["Competitor_Price_USD"])
    / df["Competitor_Price_USD"] * 100
).round(1)
at_risk = df[df["Days_Of_Stock"] > season_days]

# 3. Output: the products that need action
print(at_risk[["Product_ID", "Days_Of_Stock", "Price_Gap_Pct"]])
HOW IT WORKS
  • Days_Of_Stock divides inventory by daily sales (section 7.4).
  • Price_Gap_Pct compares our price with the competitor's: negative means we are cheaper.
  • df[df["Days_Of_Stock"] > season_days] keeps the products that will not sell out in 12 days.
READ THE OUTPUT
Product_ID Days_Of_Stock Price_Gap_Pct 0 PRD-200 14.1 -3.9 1 PRD-201 13.6 2.5 ...
  • 6 of 12 products would still have stock at the end of the season.
