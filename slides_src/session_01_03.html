MODULE 16. Keywords
Six Terms You Need Today
TOOLS

pandas and NumPy

What: free Python libraries for tables (pandas) and fast number arrays (NumPy)

Why: they sort, filter, and calculate tables of any size

INPUT

CSV file and pd.read_csv()

What: a plain-text table where commas separate values; pd.read_csv() loads it

Why: most business systems export data as CSV

TABLE

DataFrame

What: a whole table in Python, with row labels and column names

Why: it is the main object you clean, calculate, and filter

COLUMN

Series

What: one column of a DataFrame, such as df["Monthly_Sales_USD"]

Why: most calculations work column by column

SPEED

Vectorized Computation

What: one formula applied to every row at once, with no loop

Why: fast, and nothing to drag down row by row

SELECTION

.loc[] vs .iloc[]

What: .loc[] selects by label or condition; .iloc[] by position number

Why: pull out exactly the rows a question needs

Example: df.iloc[0:2, 0:3] = first 2 rows, first 3 columns

MODULE 19. Code Demonstration 2
Calculate New Columns Without a Loop
 YourName_S13_demo_2.pyInput → Process → Output
# 1. Input: load the store data
import pandas as pd
df = pd.read_csv("data/session_01_03_dataset.csv")

# 2. Process: profit and margin for every store at once
df["Operating_Profit_USD"] = (
    df["Monthly_Sales_USD"] - df["Operating_Cost_USD"]
)
df["Operating_Margin_Pct"] = (
    df["Operating_Profit_USD"] / df["Monthly_Sales_USD"] * 100.0
)

# 3. Output: show the first three stores
print(df[["Store_ID", "Monthly_Sales_USD",
          "Operating_Margin_Pct"]].head(3))
1. INPUT

Same load step as Demo 1

Why: every script loads its own data before it can calculate

2. PROCESS

df["Column_Name"] with - / *

Picks a column (a Series); the math runs on all 12 stores at once

Why: no loop and no dragging a formula down

3. OUTPUT

df[[ ... ]] double brackets

A list of column names returns a smaller table

Why: show only what your reader needs

MODULE 19. Code Demonstration 3
Filter Rows and Fill Missing Values
 YourName_S13_demo_3.pyInput → Process → Output
# 1. Input: load the store data
import pandas as pd
df = pd.read_csv("data/session_01_03_dataset.csv")

# 2. Process: keep West stores with sales of $150,000+
west_high_sales = df.loc[
    (df["Region_Name"] == "West")
    & (df["Monthly_Sales_USD"] >= 150000.0)
]
#    then fill missing satisfaction scores with the median
median_score = df["Customer_Satisfaction_Score"].median()
df["Customer_Satisfaction_Score"] = (
    df["Customer_Satisfaction_Score"].fillna(median_score)
)

# 3. Output: show the filtered stores and the median
print(west_high_sales[["Store_ID", "Monthly_Sales_USD"]])
print("Median Satisfaction Score Imputed:", median_score)
1. INPUT

Same load step as Demo 1

Why: every script loads its own data first

2. PROCESS

.loc[], &, .fillna()

  • df.loc[condition] keeps rows where the condition is True
  • & means "and"; wrap each condition in ( )
  • .fillna() fills empty cells (NaN) with the middle value (today's dataset has none)
3. OUTPUT

print() the answer

Shows the filtered stores and the median score
