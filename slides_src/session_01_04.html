THE BUSINESS SITUATION

The Quarterly Budget Review

  • Each division gets a spending budget every quarter
  • Finance compares the budget with what was actually spent
  • Our case: 4 divisions × 4 quarters = 16 rows in one CSV file
  • The finance director asks: who overspent, by how much, and who is responsible?

Today, Python answers this for the whole year at once.

Today's flow: 60 min lecture, then 120 min hands-on lab

EXPECTED OUTCOMES

By the end of today, you will be able to:

  1. "Which quarters went over budget?" Filter rows with a Boolean mask and & Boolean mask: a True/False value for every row
  2. "How much did each division overspend this year?" Summarize groups with groupby() and .agg() groupby(): split rows into groups, like an Excel pivot table (a summary with one row per group)
  3. "Who is responsible?" Join tables with pd.merge() and fix a KeyError pd.merge(): join two tables on a shared column, like Excel's VLOOKUP lookup formula

MODULE 16. Keywords
Six Terms You Need Today
FILTER

Boolean Mask

What: one True or False per row

Why: picks exactly the rows that meet a rule

COMBINE RULES

& | ~

What: "and", "or", "not" for masks

Why: Python's and / or fail on whole columns

PATTERN

Split-Apply-Combine

What: split rows into groups, calculate each group, combine the results

Why: the idea behind every pivot table

SUMMARY

groupby() + .agg()

What: groupby() splits; .agg() sums, counts, or averages each group

Why: yearly totals per division in one step

JOIN

pd.merge()

What: joins two tables row by row

Why: adds facts from another table, such as the VP's name, with no copy-paste

MATCH

Key Column

What: a column both tables share, such as Cost_Center_Code

Why: tells pandas which rows belong together

MODULE 19. Code Demonstration 1
Find Overspending with a Boolean Mask
 YourName_S14_demo_1.pyInput → Process → Output
# 1. Input: load the quarterly budget data
import pandas as pd
df = pd.read_csv("data/session_01_04_dataset.csv")

# 2. Process: Consumer quarters that spent more than budget
mask = (
    (df["Division_Name"] == "Consumer")
    & (df["Actual_Expense_USD"] > df["Budget_Expense_USD"])
)
overruns = df[mask]

# 3. Output: count and list them
print("Consumer overrun quarters:", len(overruns))
print(overruns[["Fiscal_Quarter", "Budget_Expense_USD",
                "Actual_Expense_USD"]])
1. INPUT

Same load step as Session 1.3

pd.read_csv() reads the 16 rows into df

2. PROCESS

mask and df[mask]

  • mask: one True / False per row
  • &: both rules must be True
  • df[mask] keeps only the True rows
3. OUTPUT

len() and a short table

The count, then the matching quarters

MODULE 19. Code Demonstration 2
Total Each Division with groupby()
 YourName_S14_demo_2.pyInput → Process → Output
# 1. Input: load the quarterly budget data
import pandas as pd
df = pd.read_csv("data/session_01_04_dataset.csv")

# 2. Process: yearly totals for each division
div_summary = df.groupby("Division_Name").agg(
    Total_Budget_USD=("Budget_Expense_USD", "sum"),
    Total_Actual_USD=("Actual_Expense_USD", "sum"),
    Quarters=("Transaction_ID", "count"),
)
div_summary["Variance_USD"] = (
    div_summary["Total_Actual_USD"]
    - div_summary["Total_Budget_USD"]
)

# 3. Output: one row per division
print(div_summary[["Total_Actual_USD", "Variance_USD"]])
1. INPUT

Same load step

Every script loads its own data

2. PROCESS

groupby() + .agg()

  • groupby("Division_Name"): 4 groups
  • Inside .agg(): New_Name=("Column", "sum")
  • Then one subtraction per division
3. OUTPUT

One row per division

4 rows instead of 16

MODULE 19. Code Demonstration 3
Add VP Names with pd.merge()
 YourName_S14_demo_3.pyInput → Process → Output
# 1. Input: budget data and a VP list (fictional names)
import pandas as pd
df = pd.read_csv("data/session_01_04_dataset.csv")
vp_info = pd.DataFrame({
    "Cost_Center_Code": ["CC-101", "CC-202", "CC-303", "CC-404"],
    "VP_Lead": ["Sarah Chen", "Marcus Vance",
                "Elena Rostova", "David Kim"],
})

# 2. Process: add VP names, then flag spending over budget
ledger = pd.merge(df, vp_info, on="Cost_Center_Code", how="left")
ledger["Over_Budget"] = (
    ledger["Actual_Expense_USD"] > ledger["Budget_Expense_USD"]
)

# 3. Output: show the first three rows
print(ledger[["Transaction_ID", "VP_Lead", "Over_Budget"]].head(3))
1. INPUT

Two tables

  • The CSV file
  • pd.DataFrame({...}) builds a small table in code: column name, then its list of values
2. PROCESS

pd.merge() + a flag

  • on= names the key column
  • how="left" keeps all 16 rows
  • > makes a True / False column
3. OUTPUT

.head(3)

The first rows, now with VP_Lead
