MODULE 26. Keywords
Six Terms You Need Today
REQUEST

HTTP GET

What: a HyperText Transfer Protocol (HTTP) request that asks a server for a page

Why: every page your browser or script reads starts with one

PAGE TEXT

HTML Tag

What: an HTML (HyperText Markup Language) label around content, such as <span class="price">

Why: tags tell you where each price or name sits

STRUCTURE

DOM Tree

What: Document Object Model: tags nested inside tags, like folders

Why: one product card holds its name, price, and stock

TOOL

Beautiful Soup (bs4)

What: a Python library that reads HTML into a searchable tree

Why: find tags by name or class in one line

ADDRESS

CSS Selector

What: a Cascading Style Sheets (CSS) address for tags: .price = class "price"

Why: .select() / .select_one() use it to pick tags

RESPONSIBILITY

Ethical Scraping

What: follow robots.txt, pause between requests, stay on public pages

Why: protects the website and your company

MODULE 27. Core Foundations
How Scraping Works
1. TEXT TO TABLE

From Tags to Rows and Columns

  • A web page is text with tags, not a table
  • Scraping picks out the values and lines them up as rows and columns
2. REPEATED CARDS

One Product Card = One Row

  • Every product sits in the same kind of tag: div.product
  • A for loop visits each card and builds one row
3. SELECT BY CLASS

Use Names, Not Positions

  • "The 3rd tag" breaks if the site adds a tag before it
  • .price follows the class name, so it is more likely to keep working
  • Still recheck after a site redesign
4. MISSING TAGS

Nothing Found = None

  • .select_one() returns None when a tag is missing
  • None.text stops the script with an AttributeError
  • Check first: if tag is not None:

MODULE 29. Code Demonstration 1
Read a Web Page with Beautiful Soup
 YourName_S21_demo_1.pyInput → Process → Output
# 1. Input: read the saved web page (HTML text)
from bs4 import BeautifulSoup
html_text = open("data/session_02_01_catalog.html").read()

# 2. Process: build the tree, then find the first product name
soup = BeautifulSoup(html_text, "html.parser")
first_name = soup.find("h3").text

# 3. Output: show what we found
print("Page title:", soup.title.text)
print("First product:", first_name)
1. INPUT

open().read()

  • Reads the saved page as one long text
  • No encoding= needed: the file has only plain English characters
  • On a live site, requests.get(url).text gives the same text (not run in class)
2. PROCESS

BeautifulSoup() and .find()

  • "html.parser": the built-in HTML reader
  • .find("h3"): the first h3 tag
  • .text: the words inside it
3. OUTPUT

soup.title.text

The page title, then the first product

MODULE 29. Code Demonstration 2
Turn Product Cards into Rows
 YourName_S21_demo_2.pyInput → Process → Output
# 1. Input: read and parse the saved web page
from bs4 import BeautifulSoup
html_text = open("data/session_02_01_catalog.html").read()
soup = BeautifulSoup(html_text, "html.parser")

# 2. Process: one dictionary per product card
products = []
for card in soup.select(".product"):
    price_text = card.select_one(".price").text
    products.append({
        "sku": card["data-sku"],
        "name": card.select_one(".name").text.strip(),
        "price_usd": float(price_text.replace("$", "")),
    })

# 3. Output: one line per product
for item in products:
    print(item)
1. INPUT

Same read and parse

The page text becomes soup

2. PROCESS

Loop over the cards

  • .select(): every card; .select_one(): one tag inside it
  • card["data-sku"]: a value stored in the tag
  • float(): "$49.50" to 49.5, after removing $
3. OUTPUT

One dictionary per product

4 lines, one per card

MODULE 29. Code Demonstration 3
From Scraped Prices to a Comparison Table
 YourName_S21_demo_3.pyInput → Process → Output
# 1. Input: prices already scraped from 3 competitor sites
import pandas as pd
df = pd.read_csv("data/session_02_01_dataset.csv")

# 2. Process: price after the advertised discount
df["Effective_Price_USD"] = (
    df["List_Price_USD"] * (1 - df["Promotion_Discount_Pct"] / 100)
).round(2)
electronics = df.loc[df["Category_Name"] == "Electronics"]

# 3. Output: compare competitors, then save the table
print(electronics[["Competitor_Name", "List_Price_USD",
                   "Effective_Price_USD"]])
electronics.to_csv("data/electronics_prices.csv", index=False)
1. INPUT

12 scraped prices

3 competitors, 4 categories, saved as CSV

2. PROCESS

Effective price

  • List price minus the discount: 299.99 × (1 - 10 / 100) = 269.99
  • .loc[] keeps the Electronics rows
3. OUTPUT

.to_csv()

  • Saves the table as a new CSV file
  • index=False: leave out the row labels
