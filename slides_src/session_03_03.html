Regression: Learning a Formula for a Number
  • Regression predicts a number (a price); classification predicts a category (spam, cancel)
  • Linear regression: price = start value + effect x feature + ...
  • It picks the effects that make the training errors smallest
  • Coefficient = change in price for one more unit, the other features held fixed

# 1. Input: 20 past sales of used iPhone 13 phones
import pandas as pd
from sklearn.linear_model import LinearRegression
from sklearn.model_selection import train_test_split
df = pd.read_csv("data/session_03_03_dataset.csv", index_col="Listing_ID")
features = ["Age_Months", "Storage_GB", "Battery_Health_Pct"]
X_train, X_test, y_train, y_test = train_test_split(
    df[features], df["Sold_Price_TWD"], test_size=0.25, random_state=42)

# 2. Process: learn a price formula from the 15 training sales
model = LinearRegression()
model.fit(X_train, y_train)

# 3. Output: the learned formula
print("Start value:", round(model.intercept_, 1))
for name, coef in zip(features, model.coef_):
    print(f"{name}: {coef:+,.1f}")
HOW IT WORKS
  • LinearRegression() creates; .fit() learns from 15 sales
  • intercept_ = start value; coef_ = one effect per feature
OUTPUT
Start value: 8776.8 Age_Months: -159.4 Storage_GB: +12.2 Battery_Health_Pct: +129.1

Quick Check: model.score(X_test, y_test) is 0.841

# 1. Input: the same sales, split, and model as Step 1
import pandas as pd
from sklearn.linear_model import LinearRegression
from sklearn.model_selection import train_test_split
from sklearn.metrics import mean_absolute_error
df = pd.read_csv("data/session_03_03_dataset.csv", index_col="Listing_ID")
features = ["Age_Months", "Storage_GB", "Battery_Health_Pct"]
X_train, X_test, y_train, y_test = train_test_split(
    df[features], df["Sold_Price_TWD"], test_size=0.25, random_state=42)
model = LinearRegression().fit(X_train, y_train)

# 2. Process: predict the 5 test phones and measure the errors
predicted = model.predict(X_test)
result = pd.DataFrame({"Actual": y_test, "Predicted": predicted.round().astype(int)})
result["Error"] = result["Predicted"] - result["Actual"]
mae_model = mean_absolute_error(y_test, predicted)
mae_guess = mean_absolute_error(y_test, [y_train.mean()] * len(y_test))

# 3. Output: each test phone, then the typical error of two ways to price
print(result)
print(f"Model: typical error NT${mae_model:,.0f}")
print(f"Guessing the average price: typical error NT${mae_guess:,.0f}")
HOW IT WORKS
  • .predict(X_test): 5 predicted prices
  • mean_absolute_error(): the typical error (MAE)
  • Benchmark: the average training price for every phone
OUTPUT

Step 3: Test Five Times (Cross-Validation)
 YourName_S33_step_3.pyInput → Process → Output
# 1. Input: all 20 sales
import pandas as pd
from sklearn.linear_model import LinearRegression
from sklearn.model_selection import cross_val_score
df = pd.read_csv("data/session_03_03_dataset.csv", index_col="Listing_ID")
features = ["Age_Months", "Storage_GB", "Battery_Health_Pct"]

# 2. Process: 5 rounds; each round tests on a different 4 phones
scores = cross_val_score(LinearRegression(), df[features], df["Sold_Price_TWD"],
                         cv=5, scoring="neg_mean_absolute_error")
errors = -scores

# 3. Output: the typical error of each round, the average, and the worst
print("Typical error per round:", errors.round().tolist())
print(f"Average: NT${errors.mean():,.0f} | Worst round: NT${errors.max():,.0f}")
HOW IT WORKS
  • cv=5: 5 rounds; each tests a different 4 phones
  • Scores come back negative; -scores gives the MAE
OUTPUT
Typical error per round: [554.0, 533.0, 233.0, 569.0, 487.0] Average: NT$475 | Worst round: NT$569

Quick Check: cv=4: average NT$511, worst NT$611
