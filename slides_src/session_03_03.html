By the end of today, you will be able to:

  3. "What will this new building sell for?" Predict the price of one new property, and fix the ValueError a one-row prediction often raises

MODULE 33. Business Context
When a Price Model Is Worth Using
KEY POINTS
  • An estimate is useful if its typical error is small compared with the price.
  • A model learns from past deals only.
  • Regression vs classification:
    • Regression predicts a number, such as a price. Today's model, linear regression, is one example.
    • Classification predicts a category, such as "fraud" or "not fraud". Logistic regression, used in Session 3.4, is one example.

MODULE 34. Data Basics
How Linear Regression Works
KEY POINTS
  • Linear regression finds the best straight-line formula: price = intercept + coefficient_1 x feature_1 + coefficient_2 x feature_2 + .... "Best" means the smallest total squared error on the training rows.
  • Reading a coefficient: the change in price for one more unit of that feature, while the other features stay the same.
  • Coefficients can surprise you.
  • Three error measures, in plain words:
AT A GLANCE
MeasureMeaningLower or higher is better?
MAE (Mean Absolute Error)the average size of the errors, in dollarslower
RMSE (Root Mean Squared Error)like MAE, but large errors count extralower
R-squaredthe share of the price differences the model explains, from 0 to 1higher

MODULE 36. Keywords
6 Terms You Need Today
TERM 1

Estimator (.fit() / .predict())

What: any Scikit-Learn model; .fit(X, y) learns from examples, .predict(X) makes predictions

Why: every model in the library uses the same two methods

TERM 2

Linear Regression

What: a model that predicts a number with a straight-line formula

Why: simple, fast, and its coefficients are easy to explain to a manager

TERM 3

Logistic Regression

What: a model that predicts the probability of a yes/no outcome

Why: the classification partner of linear regression (Session 3.4)

TERM 4

RMSE and MAE

What: the typical prediction error, in the target's own unit (here, dollars)

Why: tells the manager how far off an estimate can be

TERM 5

Cross-Validation

What: splitting the data into K parts and testing K times, each time on a different part

Why: one lucky split can make a model look better than it is

TERM 6

Overfitting

What: a model that memorizes its training rows and does worse on new data

Why: the main risk when data is small; testing on unseen rows reveals it

MODULE 39. Code Demonstration 1
Train a Price Model
 YourName_S33_demo_1.pyInput → Process → Output
# 1. Input: load the sales and split them
import pandas as pd
from sklearn.linear_model import LinearRegression
from sklearn.model_selection import train_test_split
df = pd.read_csv("data/session_03_03_dataset.csv")
features = ["Square_Feet_Units", "Bedrooms_Count", "Distance_To_CBD_Miles"]
X = df[features]
y = df["Sale_Price_USD"]
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.25, random_state=42
)

# 2. Process: learn the price formula from the training rows
model = LinearRegression()
model.fit(X_train, y_train)

# 3. Output: the learned formula
print("Intercept:", round(model.intercept_, 1))
for name, coef in zip(features, model.coef_):
    print(f"{name}: {coef:,.1f}")
HOW IT WORKS
  • First time only, in the Terminal: pip install scikit-learn
  • features = [...] lists the 3 input columns; X = df[features] and y = df["Sale_Price_USD"] separate inputs and answer (Session 3.2).
  • train_test_split(..., test_size=0.25, random_state=42) keeps 4 of the 14 sales aside for testing.
READ THE OUTPUT
Intercept: 123568.1 Square_Feet_Units: 180.1 Bedrooms_Count: 14,703.6 Distance_To_CBD_Miles: -1,915.8
  • Each extra square foot adds about $180, each extra room about $14,700, and each extra mile from the center subtracts about $1,900, with the other features held fixed (section 7.2).

MODULE 39. Code Demonstration 2
Predict the Test Sales and Measure the Error
 YourName_S33_demo_2.pyInput → Process → Output
# 1. Input: load, split, and train (same as Micro-Example 1)
import numpy as np
import pandas as pd
from sklearn.linear_model import LinearRegression
from sklearn.model_selection import train_test_split
from sklearn.metrics import mean_squared_error
df = pd.read_csv("data/session_03_03_dataset.csv")
features = ["Square_Feet_Units", "Bedrooms_Count", "Distance_To_CBD_Miles"]
X_train, X_test, y_train, y_test = train_test_split(
    df[features], df["Sale_Price_USD"], test_size=0.25, random_state=42
)
model = LinearRegression().fit(X_train, y_train)

# 2. Process: predict the 4 test sales and compute the RMSE
y_pred = model.predict(X_test)
rmse = np.sqrt(mean_squared_error(y_test, y_pred))
comparison = pd.DataFrame({
    "Property_ID": df.loc[X_test.index, "Property_ID"],
    "Actual_USD": y_test,
    "Predicted_USD": y_pred.round(0),
})

# 3. Output: actual vs predicted, then the typical error
print(comparison)
print(f"Test RMSE: ${rmse:,.0f}")
HOW IT WORKS
  • Part 1 loads, splits, and trains, as in Micro-Example 1.
  • model.predict(X_test) returns 4 estimated prices.
  • mean_squared_error() averages the squared errors; np.sqrt() (square root, from NumPy) brings the result back to dollars: the RMSE (section 7.3).
READ THE OUTPUT
Property_ID Actual_USD Predicted_USD 9 PROP-409 465000.0 460268.0 11 PROP-411 330000.0 345735.0 ...
  • The model is close on the large building (PROP-412: off by $2,141) and on PROP-409.

MODULE 39. Code Demonstration 3
Five Splits Instead of One
 YourName_S33_demo_3.pyInput → Process → Output
# 1. Input: load the sales
import pandas as pd
from sklearn.linear_model import LinearRegression
from sklearn.model_selection import cross_val_score
df = pd.read_csv("data/session_03_03_dataset.csv")
features = ["Square_Feet_Units", "Bedrooms_Count", "Distance_To_CBD_Miles"]

# 2. Process: train and test 5 times, each time on a different part
scores = cross_val_score(LinearRegression(), df[features],
                         df["Sale_Price_USD"], cv=5, scoring="r2")

# 3. Output: the 5 scores and their average
print("R-squared per fold:", scores.round(3).tolist())
print(f"Average R-squared: {scores.mean():.3f}")
HOW IT WORKS
  • cross_val_score(LinearRegression(), X, y, cv=5, scoring="r2") does all the work of section 7.4: it cuts the 14 sales into 5 folds, trains 5 fresh models, and tests each one on its own fold.
  • It returns 5 scores, one per fold.
  • scores.mean() averages them.
READ THE OUTPUT
  • Every fold scores above 0.99: the model does well no matter which sales are held out, not just on one lucky split.
