MODULE 24. Data Basics
What Makes a Pipeline Reproducible
KEY POINTS
  • A reproducible pipeline runs from top to bottom and produces the same numbers on any computer.
  • Three habits that make a script reproducible:
    • Use relative paths such as data/..., never paths that only exist on your computer, such as C:/Users/Reacher/Desktop/...
    • Calculate every number from the data; never type a result into the code by hand
    • Before presenting, delete your output files and run the script again from the start

MODULE 26. Keywords
6 Terms You Need Today
TERM 1

Reproducible Pipeline

What: one script that goes from the raw file to the final report, with no manual steps

Why: anyone can rerun it and check your numbers

TERM 2

Function (def / return)

What: a named block of code that takes inputs and gives back a result

Why: each pipeline stage gets a clear name, and you can reuse it

TERM 3

Relative Path

What: a file path that starts from the project folder, such as data/session_02_04_dataset.csv

Why: works on every computer that has the project folder

TERM 4

Data Type and TypeError

What: text (str) and numbers (float, int) are different types; "Total: " + 204.3 raises a TypeError

Why: printing a result is where this mistake happens most

TERM 5

Executive Finding

What: a finding, its evidence, and a recommendation

Why: managers act on clear statements backed by numbers, not on code

TERM 6

Peer Review

What: a classmate checks your script against a short checklist

Why: a second reader catches mistakes the author no longer sees

MODULE 29. Code Demonstration 1
From GMV to Cash, Row by Row
 YourName_S24_demo_1.pyInput → Process → Output
# 1. Input: load the quarterly results
import pandas as pd
df = pd.read_csv("data/session_02_04_dataset.csv")

# 2. Process: revenue, then OCF margin, for every row
df["Revenue_USD_M"] = (
    df["Gross_Merchandise_Value_USD_M"] * df["Platform_Take_Rate_Pct"] / 100
).round(2)
df["OCF_Margin_Pct"] = (
    df["Operating_Cash_Flow_USD_M"] / df["Revenue_USD_M"] * 100
).round(1)

# 3. Output: the 3 rows with the lowest margin
lowest = df.sort_values("OCF_Margin_Pct").head(3)
print(lowest[["Quarter_Code", "Market_Segment", "OCF_Margin_Pct"]])
HOW IT WORKS
  • The first calculation multiplies each row's GMV by that row's take rate and divides by 100: revenue in USD millions.
  • The second divides each row's OCF by its revenue: the OCF margin, the share of revenue that became cash.
  • df.sort_values("OCF_Margin_Pct") orders the rows from the lowest margin to the highest, and .head(3) keeps the 3 lowest.
READ THE OUTPUT
Quarter_Code Market_Segment OCF_Margin_Pct 8 2024-Q1 Asia_Pacific 15.0 5 2024-Q2 Asia_Pacific 16.8 2 2024-Q3 Asia_Pacific 18.6
  • The 3 weakest quarters all belong to Asia Pacific: in Q1, only 15.0 cents of every revenue dollar became cash.

MODULE 29. Code Demonstration 2
The Same Work as a Pipeline of Functions
 YourName_S24_demo_2.pyInput → Process → Output
# 1. Input: a function that loads and checks the raw file
import pandas as pd

def load_data(path):
    df = pd.read_csv(path)
    assert (df["Gross_Merchandise_Value_USD_M"] > 0).all(), "GMV must be above 0"
    return df

# 2. Process: functions that add measures and summarize by region
def add_metrics(df):
    df["Revenue_USD_M"] = (
        df["Gross_Merchandise_Value_USD_M"] * df["Platform_Take_Rate_Pct"] / 100
    ).round(2)
    return df

def summarize(df):
    summary = df.groupby("Market_Segment").agg(
        Revenue_USD_M=("Revenue_USD_M", "sum"),
        OCF_USD_M=("Operating_Cash_Flow_USD_M", "sum"),
    )
    summary["OCF_Margin_Pct"] = (
        summary["OCF_USD_M"] / summary["Revenue_USD_M"] * 100
    ).round(1)
    return summary

# 3. Output: run the stages in order, then print and save
df = load_data("data/session_02_04_dataset.csv")
df = add_metrics(df)
summary = summarize(df)
print(summary)
summary.to_csv("data/region_summary.csv")
HOW IT WORKS
  • load_data(path) reads the file and checks with assert that every GMV is above 0; bad data stops the pipeline here (section 7.2).
  • add_metrics(df) adds the revenue column and returns the table.
  • summarize(df) groups by region, sums revenue and OCF, and computes each region's margin from its totals (section 7.5).
READ THE OUTPUT
  • Asia Pacific earns the most revenue (70.39) but keeps the least as cash (18.5%).

MODULE 29. Code Demonstration 3
Write the Findings for the CFO
 YourName_S24_demo_3.pyInput → Process → Output
# 1. Input: load the data and build the region summary
import pandas as pd
df = pd.read_csv("data/session_02_04_dataset.csv")
df["Revenue_USD_M"] = (
    df["Gross_Merchandise_Value_USD_M"] * df["Platform_Take_Rate_Pct"] / 100
).round(2)
summary = df.groupby("Market_Segment").agg(
    Revenue_USD_M=("Revenue_USD_M", "sum"),
    OCF_USD_M=("Operating_Cash_Flow_USD_M", "sum"),
)

# 2. Process: margin, then the best region by margin
summary["OCF_Margin_Pct"] = (
    summary["OCF_USD_M"] / summary["Revenue_USD_M"] * 100
).round(1)
ranked = summary.sort_values("OCF_Margin_Pct", ascending=False)
best_region = ranked.index[0]
best_margin = ranked["OCF_Margin_Pct"].iloc[0]

# 3. Output: finding, evidence, recommendation
print(f"Finding: {best_region} turns the most revenue into cash.")
print(f"Evidence: its OCF margin is {best_margin}%.")
print("Recommendation: study its cost structure before expanding elsewhere.")
HOW IT WORKS
  • Part 1 rebuilds the region summary, as in Micro-Example 2.
  • summary.sort_values("OCF_Margin_Pct", ascending=False) puts the best margin first.
  • ranked.index[0] reads the first row label, here the name of the best region.
READ THE OUTPUT
  • The region and the margin come from the data, not from typing: if next year's file changes, the sentence changes with it.
