MODULE 23. Business Context
A Chart Answers One Question
KEY POINTS
  • A table makes the reader hunt for the pattern; a chart shows it.
  • Five rules for charts that executives trust:
    • One message per chart, and the title states it, for example "Revenue More Than Doubled from Jan to Dec"
    • Label every axis with its unit, such as "USD M" (millions of U.S. Dollars)
    • Bar charts start at zero; a cut-off axis makes small differences look huge
    • No 3D effects or decoration; every mark on the chart should carry data
    • Use colors that still work in black-and-white print and for color-blind readers

MODULE 24. Data Basics
Pick the Chart from the Question
KEY POINTS
  • Correlation measures how closely two columns move together, on a scale from -1 to +1:
    • +1: when one goes up, the other always goes up
    • 0: no straight-line pattern
    • -1: when one goes up, the other always goes down
  • Correlation is not causation.

MODULE 26. Keywords
6 Terms You Need Today
TERM 1

Matplotlib and Seaborn

What: Python charting libraries; Seaborn adds quick, clean statistical charts on top of Matplotlib

Why: they turn a DataFrame into a chart image with a few lines of code

TERM 2

Figure and Axes

What: the Figure is the whole image; each Axes is one chart inside it

Why: you draw on a specific Axes, so a dashboard can hold several charts

TERM 3

Line Chart

What: points joined in time order

Why: shows trends, such as monthly revenue

TERM 4

Bar Chart

What: one bar per category; the bar length is the value

Why: compares sizes, such as spend by month

TERM 5

Scatter Plot

What: one dot per row, with one column on each axis

Why: shows whether two numbers move together

TERM 6

Correlation Heatmap

What: a grid of correlations, colored from -1 to +1

Why: spots which of many numbers move together, in one picture

MODULE 29. Code Demonstration 1
Line Chart: Revenue Trend
 YourName_S22_demo_1.pyInput → Process → Output
# 1. Input: load the monthly results
import pandas as pd
import matplotlib.pyplot as plt
df = pd.read_csv("data/session_02_02_dataset.csv")

# 2. Process: one figure with one chart, revenue by month
fig, ax = plt.subplots(figsize=(10, 5))
ax.plot(df["Month_Name"], df["Organic_Revenue_USD_M"],
        color="#991B1B", marker="o")
ax.set_title("Revenue More Than Doubled from Jan to Dec")
ax.set_ylabel("Organic Revenue (USD M)")

# 3. Output: save the chart as an image file
fig.savefig("data/revenue_trend.png", dpi=150, bbox_inches="tight")
print("Saved: data/revenue_trend.png")
HOW IT WORKS
  • First time only, in the Terminal: pip install matplotlib seaborn
  • import matplotlib.pyplot as plt loads Matplotlib's charting tools under the short name plt.
  • plt.subplots(figsize=(10, 5)) creates the Figure (10 inches wide, 5 tall) and one Axes, named fig and ax (section 7.1).
READ THE OUTPUT
Saved: data/revenue_trend.png
  • The Terminal only confirms the file; the chart itself is in data/revenue_trend.png.

MODULE 29. Code Demonstration 2
Bar Chart: Marketing Spend by Month
 YourName_S22_demo_2.pyInput → Process → Output
# 1. Input: load the monthly results
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
df = pd.read_csv("data/session_02_02_dataset.csv")

# 2. Process: one bar per month
fig, ax = plt.subplots(figsize=(10, 4))
sns.barplot(data=df, x="Month_Name", y="Paid_Marketing_Spend_USD_M",
            color="#475569", ax=ax)
ax.set_title("Marketing Spend Peaks in November and December")
ax.set_xlabel("")
ax.set_ylabel("Paid Marketing Spend (USD M)")

# 3. Output: save the chart
fig.savefig("data/marketing_spend_bar.png", dpi=150, bbox_inches="tight")
print("Saved: data/marketing_spend_bar.png")
HOW IT WORKS
  • import seaborn as sns loads Seaborn, which draws common statistical charts with less code than Matplotlib alone.
  • sns.barplot(data=df, x="Month_Name", y="Paid_Marketing_Spend_USD_M", ...) reads the columns by name from the DataFrame and draws one bar per month.
  • Seaborn's bars start at zero, so their lengths can be compared honestly (section 7.6).
READ THE OUTPUT
Saved: data/marketing_spend_bar.png
  • In the image, the bars grow through the year, and the last two are clearly the tallest: Nov 5.2 and Dec 6.4, against 2.1 in Jan.

MODULE 29. Code Demonstration 3
Correlation Heatmap
 YourName_S22_demo_3.pyInput → Process → Output
# 1. Input: load the monthly results
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
df = pd.read_csv("data/session_02_02_dataset.csv")

# 2. Process: correlation between every pair of 4 columns
cols = ["Organic_Revenue_USD_M", "Paid_Marketing_Spend_USD_M",
        "Customer_Acquisition_Cost_USD", "Net_Promoter_Score"]
corr = df[cols].corr().round(2)
fig, ax = plt.subplots(figsize=(8, 6))
sns.heatmap(corr, annot=True, cmap="RdBu_r", vmin=-1, vmax=1, ax=ax)
ax.set_title("All Four Measures Rose Together in 2024")

# 3. Output: print the numbers, then save the chart
print(corr)
fig.savefig("data/kpi_correlation_heatmap.png", dpi=150,
            bbox_inches="tight")
HOW IT WORKS
  • cols = [...] lists the 4 measures to compare.
  • df[cols].corr() computes the correlation of every pair, a 4 x 4 table (section 7.3).
  • sns.heatmap(corr, annot=True, cmap="RdBu_r", vmin=-1, vmax=1, ax=ax) colors each cell: red for positive, blue for negative, white near zero.
READ THE OUTPUT
  • The ... hides middle columns that do not fit the Terminal width; the image shows all 16 cells.
